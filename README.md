# cicekci-sitesi
Responsive flower shop website design built with HTML and CSS

Çiçekçi Sitesi


HTML5 ve CSS3 kullanilarak gelistirilmis, tamamen duyarli bir e-ticaret cicekci web sitesi tasarimi.

Ozellikler
- Responsive Tasarim: Mobil, tablet ve masaustu cihazlarla tam uyumlu.
- Modern Arayuz: Flexbox ve CSS Grid kullanilarak tasarlanmis duzenler.
- Zengin Bolumler: Anasayfa, Hakkimizda, Hizmetler, Urunler, Musteri Yorumlari ve Iletisim alanlari.
- Font Awesome Ikonlari: Modern ikon destegi.

Kullanilan Teknolojiler
- HTML5
- CSS3
- Font Awesome 6.5.1
